# Personal Portfolio — React & Vite

A personal portfolio website built with React to showcase my skills, projects, and services as a developer.

🌐 **Live Demo:** [View My Portfolio](https://elsaman0udy.github.io/My_Portfolio/)

## Overview

This portfolio serves as a central place to explore my background, technical skills, selected projects, and contact information. It features a responsive interface designed to provide a clear and accessible browsing experience across different screen sizes.

## Features

- **Home:** Introduction and personal profile.
- **About Me:** Background and developer information.
- **Skills:** Overview of technical skills and technologies.
- **Services:** An introduction to the services I offer.
- **Projects:** A showcase of selected projects.
- **Contact:** Contact section for professional inquiries.
- **Responsive Design:** Layout designed for desktop and mobile screens.

## Tech Stack

- **React** — Building reusable UI components.
- **JavaScript (ES6+)** — Application logic and interactivity.
- **Vite** — Development server and production build tooling.
- **CSS3** — Styling and page layouts.
- **Git & GitHub** — Version control and source code hosting.
- **GitHub Pages & GitHub Actions** — Automated deployment.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ELSAMAN0UDY/My_Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd My_Portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To build the project for production, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```

## Deployment

The project is deployed using GitHub Pages. GitHub Actions automatically builds and deploys the application when changes are pushed to the `main` branch.
